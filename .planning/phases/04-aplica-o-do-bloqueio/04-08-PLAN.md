<objective>
Criar o habilitador de teste que falta e provar a fase ponta a ponta contra Postgres real: um script
de seed sob `scripts/` que escreve os fatos de billing direto no banco, e um spec de Playwright que
percorre o ciclo inteiro — empresa saudável → bloqueada → paga → liberada.

Purpose: o allowlist de `empresaService.update` proíbe DELIBERADAMENTE a escrita de `acessoAte`,
`trialFim`, `canceladoEm` e `acessoVitalicio` por HTTP (BILL-04, decisão `[02-02]`). Não existe
caminho de API legítimo para montar uma fixture de empresa bloqueada, e abrir um seria desfazer uma
decisão de segurança de outra fase. O script de seed é o padrão já aprovado na Fase 3 (`03-07`) e
mantém a dívida fora do código de produção.

Output: `scripts/seed-fatos-billing.ts`, o script npm `seed:billing`, e
`e2e/bloqueio-por-inadimplencia.spec.ts`.
